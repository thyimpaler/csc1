## Detailed Description (for README intro or website)

CryptoIntel Pro is a private, high-performance crypto intelligence dashboard designed for serious market researchers and traders who need a sophisticated tool to track All-Time High (ATH) performers across multiple timeframes.

**What makes it unique:**

Unlike generic portfolio trackers, CryptoIntel Pro focuses on the research phase of trading. It provides a probability-weighted approach to tracking opportunities, where each coin can be assigned a confidence score (0-100%) and a setup grade (A/B/C). The dashboard automatically categorizes coins by sector (L1, L2, DePIN, Memes, DeFi, Gaming, AI) and calculates real-time correlation coefficients with Bitcoin and Ethereum.

**Key capabilities:**

- **Live Market Data**: Sub-second price updates via Binance WebSocket
- **Probability Scoring**: Assign confidence levels that optionally decay over time
- **Correlation Analysis**: Real-time BTC/ETH beta tracking
- **Order Book Visualization**: Top 5 bid/ask levels with quantity heatmaps
- **ATH Distance Tracking**: Monitor how close each coin is to its recent highs
- **Research Notes**: Document your analysis directly on each coin

The interface features a sleek terminal theme with pure black backgrounds and neon accents, providing a professional trading aesthetic. All data persists in your browser's localStorage, requiring no backend infrastructure or API keys (Binance WebSocket is public).

Built with Next.js 14, React 18, Tailwind CSS, Zustand for state management, and Framer Motion for smooth animations. The entire application is client-side and can be deployed to Vercel in under 3 minutes.
